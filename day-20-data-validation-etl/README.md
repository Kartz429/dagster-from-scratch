## What is Data Validation?

Checking whether data is correct before processing.

Examples:

✅ Marks = 95

❌ Marks = -10

❌ Marks = 150

---

## ETL Flow

```text
students.csv
      ↓
   Extract
      ↓
Validate Data
      ↓
Transform Data
      ↓
Load Output Files
      ↓
Analytics Report
```
